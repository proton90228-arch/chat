# Соответствие Java-лаунчеру 1.x

| Java (1.x) | Valkyrie Launcher 2 |
| --- | --- |
| `LauncherConfig` (properties, миграция путей, авто-память 2/3/4/6 ГБ) | `core/config.rs`, `core/properties.rs` |
| `GameVersion`, каталог Mojang | `core/version.rs`, `core/catalog.rs` (+ кэш для офлайна) |
| `MinecraftInstaller` (клиент, библиотеки, natives, assets, SHA-1) | `core/install.rs`, `core/net.rs` |
| `ForgeInstaller` (installer.jar, таймаут 15 мин) | `core/install.rs` |
| `JavaRuntimeManager` (Mojang runtime, Adoptium, своя Java) | `core/java.rs` |
| `MinecraftLauncher` (аргументы, правила, офлайн-UUID) | `core/launch.rs`, `core/profile.rs`, `core/uuid.rs` |
| `ClientUpdater` (манифест, SHA-256, встроенный jar) | `core/update.rs` |
| `LaunchState` и сценарии `ValkyrieLauncherApp` | `core/status.rs`, `ui/src/core/launchState.ts`, `ui/src/app/controller.ts` |
| `SakuraBackground` | `ui/src/sakura/sim.ts` (сверено с оригиналом, `tools/golden`) |
| `LauncherSounds` (click/open/close/type, 3 голоса, 48 мс) | `ui/src/sound/sounds.ts`, `ui/public/sounds` |
| Окно 1040×650, своя строка заголовка, перетаскивание | `tauri.conf.json`, `screens/TitleBar.tsx`, `App.tsx` |
| Библиотека версий, Settings, Changelog, тосты | `screens/*`, `components/Toasts.tsx` |
| MSI (jpackage) | NSIS currentUser + удаление MSI (`windows/hooks.nsh`) |

## Сознательные отличия

- На время проверки статуса кнопка запуска заблокирована (в Java после смены версии можно было
  нажать «Запустить» со старым состоянием).
- «Игра запущена · <версия>» вместо удвоенной строки статуса Java.
- Новая фаза установки (`stage`) обнуляет полосу прогресса, а не оставляет её на 100 %.
- Минимальная высота окна 560 вместо 540: новая карточка выше из-за полей M3.
- Новые функции: палитры и акцент Windows, автообновление лаунчера, экран фатальной ошибки.
