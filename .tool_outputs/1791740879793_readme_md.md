# IPC-контракты

JSON-образцы сообщений между Rust (`valkyrie-core`, `src-tauri`) и интерфейсом (`ui/src/ipc/types.ts`).
Оба набора тестов читают эти файлы: `cargo test -p valkyrie-core --test contracts` проверяет
сериализацию Rust-типов, `npm --prefix ui test` проверяет TypeScript-гарды. Меняя тип с одной стороны,
обновите образец, иначе упадут обе проверки.
