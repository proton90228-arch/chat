# VALKYRIE CLIENT 0.9 BETA

Первая публичная beta-сборка Valkyrie для Minecraft Forge 1.21.10.

Valkyrie - чистый модульный клиент без сотен дублирующих функций. Только основные Combat-инструменты, аккуратные визуалы и единый Sakura-интерфейс.

## Combat

- Valkyrie Flow KillAura: Legacy / Modern / Hybrid
- Aim Assist и TriggerBot
- AutoWeapon и AutoTotem
- Natural Criticals без position spoof
- Raycast-проверка, динамическая точка наведения и единый Combat pipeline

## Visuals

- Sakura Combat Bloom
- Target HUD и Target Glow
- Threat Constellation, Intent Lens и Memory Echo
- ESP, Storage ESP и Block Highlight
- Pearl Prediction и Projectile Trails
- Item Animations, Camera Effects и World Color

## Client

- ClickGUI с анимированным Book Fold
- HUD Editor
- светлая и темная Sakura-темы
- Focus Mode и Visual Profiles
- живой компаньон с ненавязчивыми реакциями
- Sakura-частицы и контекстные фразы

Minecraft: 1.21.10
Forge: 60.1.0+
Java: 21

Это beta-версия. Перед обновлением сохраните конфигурацию. Использование Combat-функций может нарушать правила серверов.
